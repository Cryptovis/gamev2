# AlpyX Global Command 0.40 — Strategic Command

This release joins three workstreams into one playable milestone.

## Game Pack 0.4
- Cabinet / six ministry budget allocation model
- Technology Tree v1 with prerequisites and research points
- Processed industry chain: oil → fuel, iron → steel, grid → electricity
- Warfare now consumes processed fuel rather than raw oil
- Alliance Bloc v1: form and invite allied states
- Global Council v1: sanctions, ceasefire and humanitarian-aid resolutions
- Council influence regeneration
- Global sanctions block commodity trade

## Visual Pack 1
- Expanded in-code SVG icon family
- Ministry visual cards with six authored SVG illustrations
- Cabinet, research, intelligence, interior, society, bloc and council icons
- Processed-resource readout for fuel, steel and electricity
- New Cabinet / Tech / World command surfaces

## Foundation Pack 1
- Config-driven ministry definitions
- Config-driven technology tree
- Save schema v7 and incompatible-save guard
- Release and playtest documentation
- Visual asset manifest

## Known scope
0.40 is still a browser grand-strategy alpha. Global Council votes and country data are gameplay simulations, not predictions or authoritative descriptions of real-world political behavior.

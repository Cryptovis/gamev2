# Leader portraits — Open Command 0.75

Generated with the built-in Imagegen tool on 7 October 2026 for this game. All subjects are fictional. These are game illustrations, not photographs of named people. No real regime or national insignia was requested.

Project assets:
- `public/assets/leaders/civilian-atlas.svg`
- `public/assets/leaders/military-atlas.svg`
- `public/assets/leaders/aviator-atlas.svg`
- `public/assets/leaders/worker-atlas.svg`

Each atlas contains exactly five equal-width portrait panels in one horizontal row. The generated originals are 1983x793 pixels. WebP encoding at quality 90 preserves the generated composition without retouching. Each SVG file is a lossless container embedding that generated WebP raster; it is not a vector substitute. This allows delivery through GitHub’s text-tree endpoint while its binary-blob endpoint is unavailable. `AvatarPortrait` displays each panel using 500% background size and a 0/25/50/75/100% horizontal position; existing profile IDs remain valid. The entire set is approximately 1.4MB before HTTP compression and loads by category through local static assets.

## Final prompt set

Shared production brief: stylized-concept; one strategy-game portrait sprite atlas, exactly five equally sized portrait tiles in a single horizontal row, edge-to-edge, no gaps, borders, lettering or watermark. Head and upper chest, full heads inside separate tiles, consistent head height/scale, no overlap. Premium realistic painted game character art, anatomically correct expressive faces, refined skin and woven cloth, soft daylight, a softly blurred slate-blue backdrop, luminous approachable faces. Fictional adult national leaders, no celebrities, weapons or real flags.
